# Notes – Developer Hints for Next Action Tool

## ⚠️ Python Package Notes

- `customtkinter` may require `tk` installed on the system (usually included with Python installations on Windows).
- If you're using Outlook automation with `win32com.client`, you must install `pywin32`.
- If you encounter issues with `customtkinter`, try updating it with:

```bash
pip install customtkinter --upgrade
